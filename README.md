# -dissolution-draft

MDBC partnership presentation — a Next.js app for the interactive slide deck.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy on Vercel

1. Import this GitHub repo at [vercel.com/new](https://vercel.com/new)
2. Framework: **Next.js**
3. Root directory: `.`
4. Build command: `next build` (default)
5. Deploy

No environment variables are required for the presentation.
